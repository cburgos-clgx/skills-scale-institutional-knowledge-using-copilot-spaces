# OctoAcme Project Management Processes

This README is the central hub for OctoAcme project management documentation. Use it to quickly understand how we run projects and to navigate to the right process guidance for your role.

## Approach at a Glance

OctoAcme uses a lightweight, iterative project management approach designed to deliver customer value in small, testable increments. Work is guided by clear ownership across Product, Project, and Engineering roles, with regular communication, risk tracking, and continuous learning through retrospectives.

### Core Principles
- Customer-first outcomes
- Iterative delivery
- Clear ownership and accountability
- Data-informed decisions
- Psychological safety and feedback

## Contributing and Updating Process Docs

To contribute updates:
1. Identify the relevant document in this `docs/` folder.
2. Propose focused edits that keep terminology and structure consistent with existing process docs.
3. When updating one process area, check related docs for cross-reference consistency.
4. Open a pull request that summarizes:
   - What changed
   - Why it changed
   - Which teams/personas are affected
5. Request review from Product and Project stakeholders when changes affect scope, cadence, or governance.

Tip: Keep updates practical and lightweight so documents remain easy to adopt and maintain.
